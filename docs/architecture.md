# Arquitectura

## Arquitectura general

```text
Cliente
   ↓
WhatsApp
   ↓
Botpress
   ↓
Backend Express
   ↓
PostgreSQL
   ↓
React Dashboard
```
## Componentes
### Botpress

Responsable de la conversación y capacidades de IA.

### Backend

Responsable de la lógica de negocio, clientes,
conversaciones, leads, citas y analíticas.

### PostgreSQL

Almacenamiento persistente.

### React

Interfaz administrativa y dashboard.
